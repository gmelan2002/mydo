# 🚀 MyDo - Your Daily Task Manager

**MyDo** is a feature-rich, lightweight, and modern To-Do application built using **Flutter** and **Dart**. It helps you manage your daily tasks efficiently with local storage, dark mode support, search/filtering, and custom calendar date tracking.

---

## ✨ Features

- **Task Management**: Easily Add, Edit, Delete, and Mark tasks as completed with a strike-through effect.
- **Local Storage**: Uses `shared_preferences` with JSON encoding/decoding to securely save your tasks locally.
- **Custom Calendar Date Picker**: Assign specific dates to tasks using Flutter's built-in date picker and filter tasks by Today, Tomorrow, Yesterday, or any custom date.
- **Search & Filter**: Instantly search through tasks by title/description and filter them by All, Active, Completed, or Date.
- **Dark & Light Mode**: Seamlessly toggle between dark and light themes with preference persistence.
- **Animated Splash Screen**: Smooth elastic animation on startup for an engaging user experience.
- **App Icon**: Custom launcher icon generated using `flutter_launcher_icons`.

---

## 🛠️ Tech Stack & Required Skills

- **Framework**: Flutter (Material Design 3)
- **Language**: Dart
- **State Management**: Stateful Widgets
- **Local Database**: `shared_preferences`, `dart:convert` (JSON)
- **Packages Used**:
  - `shared_preferences`
  - `flutter_native_splash`
  - `flutter_launcher_icons`
